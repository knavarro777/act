Interactive Web Application (.NET Blazor)

## Project Description
This project is a web application built using **C# and .NET Blazor**. It features a collection of practical tools, mathematical utilities, and interactive personal sections integrated into a responsive web interface.

---

## Key Modules and Features

The main modules included in this project are:

### 1. Personal Section
* **My Story (`MiHistoria.razor`):** An interactive page presenting personal background, career paths, academic background, and hobbies using custom images (`carrera.jpg`, `formacion.jpg`, `hobbies.jpg`).

### 2. Practical Utilities
* **Currency Exchange (`CambioMoneda.razor`):** A currency converter tool for quick monetary exchange calculations.
* **Days of the Month (`DiaMes.razor`):** A calendar component to check and identify days and months.
* **To-Do List (`Porhacer.razor`):** A task management tool to add, track, and organize pending activities.

### 3. Logic and Math Tools
* **List of Numbers (`Lnumeros.razor`):** A module for processing, displaying, and manipulating numeric sequences.
* **Prime Numbers (`Numprimos.razor`):** An interactive tool to calculate and verify prime numbers.

### 4. Base & Demo Components
* **Counter (`Counter.razor`):** A classic interactive counter demonstrating state management in Blazor.
* **Weather (`Weather.razor`):** A component displaying weather data forecasts.

---

## Technologies Used

* **Programming Language:** C# (.NET 8)
* **Web Framework:** Blazor
* **Styling & UI:** Bootstrap and custom CSS (`app.css`, `NavMenu.razor.css`, `MainLayout.razor.css`)
